# Equatile

A Scrabble-style board game with number tiles. Every line of touching tiles must read as a true equation: `972671` reads as `97 − 26 = 71`.

## What's here

- `index.html`, `how-to-play/`, `support/`, `privacy/`, `terms/`, `404.html`: the equatile.com website, generated by `tools/build_site.py` (edit the script, then run `python3 tools/build_site.py`).
- `play/index.html`: the whole game in one page (vs computer, pass and play, daily and random puzzles, online play, workbench).
- `assets/`: shared site styles, the hero demo script, icons and the social share image.
- `supabase/functions/equatile/`: the server function for online play. It deals tiles, keeps racks and the bag hidden, and checks every move.
  - `engine.js` is generated from the rules code in `play/index.html`, so the page and the server always score the same way.
- `supabase/migrations/`: the database tables for online games, in a private `equatile` schema.

## Online play

The page talks to the `equatile` function on Supabase. One player starts a game and shares a 6-character code or an invite link (`/play/#join-CODE`); the other joins with it. No accounts yet.
